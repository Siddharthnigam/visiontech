 VISION TECH — Design System: Bespoke Visual Identity

Context: The architecture from Prompt 1 is complete (JavaScript/JSX, not TypeScript). 
This pass defines the VISUAL LANGUAGE only — typography, color application, spacing, 
motion, and texture. The explicit goal is that this site must NOT look like a 
templated AI-generated SaaS landing page. Avoid every cliché listed in Section 0 
without exception.

## 0. Hard "Do Not" List (these are instant fails)
- No centered hero with a giant rounded gradient blob behind a floating dashboard 
  mockup screenshot.
- No Inter/Geist/default system font used at default weights — pick a deliberate 
  typographic pairing (see Section 1).
- No generic 3-icon-in-a-row "feature cards" with a colored circle behind a 
  Lucide icon and identical corner radius on every card.
- No purple-to-blue or blue-to-cyan gradient text on headlines.
- No stock "trusted by" logo strip using recognizable big-tech logos.
- No symmetrical, perfectly centered layouts on every section — vary rhythm.
- No overuse of `rounded-2xl` + `shadow-xl` + `backdrop-blur` combo on every 
  single card (this is the #1 tell of AI-generated UI).
- Avoid the default Tailwind spacing rhythm (everything in exact multiples of 8 
  with no intentional asymmetry) — introduce deliberate irregular spacing that 
  reads as "designed by hand," not "generated by a component library."

## 1. Typography System
- Choose ONE distinctive display/heading font (self-hosted or via `next/font/google`, 
  e.g. a serif-influenced or condensed grotesk like "Space Grotesk," "General Sans," 
  or "Söhne"-adjacent alternative — NOT Inter, NOT Poppins, NOT Montserrat).
- Pair it with a highly readable body font with distinct x-height contrast.
- Define a modular type scale in `globals.css` using CSS clamp() for fluid 
  responsive sizing (no fixed breakpoints jumps).
- Headlines should use tight letter-spacing (negative tracking) and asymmetric 
  line-breaks — not centered three-line generic hero copy.

## 2. Color Application Rules (using the existing navy/brand/ice/white tokens)
- Navy (#0B192C) is the dominant background for high-impact sections (hero, CTA 
  band, footer) — NOT just used as text color.
- White sections should not be flat #FFFFFF everywhere — introduce a near-white 
  `#FAFBFC` and the ice-blue (#E0F2FE) as alternating section backgrounds to 
  create visual rhythm without needing colorful illustrations.
- Brand blue (#0066FF) is used SPARINGLY as an accent (CTAs, underlines, active 
  states, key stat numbers) — never as a full-section background gradient.
- Add one unexpected accent moment: a thin animated gradient line/rule, or a 
  single warm off-palette highlight color used only once (e.g., on a "limited 
  spots" badge) to break monotony.

## 3. Layout & Composition
- Break the "container centered, everything stacked" pattern: use asymmetric 
  grids (e.g., 60/40 splits, offset columns, a sidebar-style sticky element 
  next to scrolling content in the Process section).
- Hero section: instead of a floating mockup, use one of these unique approaches — 
  (a) an abstract geometric/wireframe SVG composition built from the brand's 
  actual services (nodes representing "web," "social," "growth" connected by 
  animated lines), or (b) a large bold typographic hero with a marquee/ticker 
  of client results running beneath it.
- Services section: replace identical icon-cards with a numbered, editorial-style 
  list (01 / 02 / 03) with large index numbers, alternating text alignment, and 
  a hover state that reveals a preview graphic per service.
- Process section: horizontal scroll-snap timeline on desktop (not four generic 
  vertical cards with arrows between them).

## 4. Motion & Micro-interactions
- Use Framer Motion for scroll-triggered reveals with staggered children — 
  vary the easing curve (custom cubic-bezier, not default ease-in-out) so 
  motion feels intentional.
- Magnetic/hover-lift buttons: slight scale + shadow shift + border color 
  transition on hover, with a subtle cursor-follow effect on primary CTAs only.
- Add a subtle grain/noise texture overlay (very low opacity, ~3-4%) on navy 
  sections to avoid a flat, sterile "AI slide" look.
- Smooth scroll with scroll-linked progress indicator in the nav.

## 5. Accessibility Guardrails (non-negotiable)
- Navy text (#0B192C) on white/ice backgrounds and white text on navy/brand 
  backgrounds must meet WCAG AA contrast (4.5:1 body text, 3:1 large text).
- Focus states must be visible (custom focus-ring using brand blue, not browser 
  default) on all interactive elements.
- Respect `prefers-reduced-motion` — disable non-essential animations for users 
  who request it.
